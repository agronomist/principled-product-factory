# Verify `kitchen-cookbook` (`/verify-kitchen-cookbook`)

Generated by [`../taste-the-dish/SKILL.md`](../taste-the-dish/SKILL.md). This skill drives the `principled-product-factory` repository the way a Head Chef or CI runner does and captures durable evidence.

## 1. Fire Up (`Launch`)

Provision an isolated scratch directory (`/tmp/kitchen-harness-scratch-<session-id>`) from an empty state:
```bash
bash skills/head-chef-mode/scripts/run-live-tasting.sh
```

## 2. Station Check (`Doctor`)

Before driving any feature—and immediately after any failed drive—verify:
- `skills/head-chef-mode/scripts/validate-skills.sh` is present and executable.
- `skills/head-chef-mode/scripts/log-decision.sh` is present and executable.
- `hooks/pre-tool-guard.sh` is present and executable.
- `.claude/skills`, `.agents/skills`, `.cursor/skills`, and `.claude/agents` symlinks resolve cleanly.

## 3. Plate (`Drive`)

Exercises the three user-facing features mapped in [`../../features/README.md`](../../features/README.md):
1. **Cookbook & Subagent Structural Validation** ([`features/cookbook-validation.md`](../../features/cookbook-validation.md)):
   ```bash
   bash skills/head-chef-mode/scripts/validate-skills.sh
   ```
2. **Pre-Tool Service-Door Bouncer Hook** ([`features/service-door-bouncer.md`](../../features/service-door-bouncer.md)):
   ```bash
   # Allowed: pushing to factory/* branch exits 0
   bash hooks/pre-tool-guard.sh "git push origin factory/ticket-101"
   # Blocked: pushing to main or merging exits 2 with FIX message
   ! bash hooks/pre-tool-guard.sh "git push origin main"
   ! bash hooks/pre-tool-guard.sh "gh pr merge 101"
   ```
3. **Prep-Log TSV Sanitization & Audit Trail** ([`features/prep-log-trail.md`](../../features/prep-log-trail.md)):
   ```bash
   bash skills/head-chef-mode/scripts/log-decision.sh \
     "<scratch>/decisions.tsv" "taste" "=SUM(1,2) formula test" "Verify sanitization" "skills/head-chef-mode/SKILL.md:1" "VERIFIED"
   ```

## 4. Proof (`Evidence`)

Writes durable proof JSON to `.audit/evidence/proof-kitchen-cookbook.json` (outside the ephemeral `/tmp/kitchen-harness-scratch-*` directory) recording exit codes, skill counts, subagent counts, and hook block confirmations.

## 5. Dishpit (`Cleanup`)

Removes `/tmp/kitchen-harness-scratch-<session-id>` completely while leaving `.audit/evidence/proof-kitchen-cookbook.json` intact on disk, and verifies `test -f .audit/evidence/proof-kitchen-cookbook.json` after teardown.

## Helpers

- Full End-to-End Live Tasting Runner: `bash skills/head-chef-mode/scripts/run-live-tasting.sh`
- Worktree Spawner (`WIP_LIMIT = 5`): `bash skills/head-chef-mode/scripts/spawn-worktree.sh <ticket-id>`
- Cross-Vendor Blind Diff Taster: `bash skills/head-chef-mode/scripts/cross-vendor-taste.sh <branch-or-range>`
- Closing-Duty Checklist: `bash skills/head-chef-mode/scripts/closing-duty.sh`
