# Principle: Food-Cost Margin Floor

Never serve a dish or sign a table contract that loses money on every plate (*the cross-state bottle-deposit mail truck*).

- Enforce pre-flight unit economics on every plate:
  $$\texttt{unit\_revenue} - (\texttt{inference\_cost} + \texttt{data\_api\_cost} + \texttt{hitl\_prob} \cdot \texttt{human\_review\_cost} + \texttt{infra\_cost}) \ge \texttt{min\_margin}$$
- If specialty frontier ingredients breach the floor, automatically substitute house-distilled stock (`secondary_distilled_model`); if still below floor, 86 the order.
- Block **Molecular-Gastronomy Foam Theater** immediately when Expected Value of Information $\text{EVOI} \le \text{Cost}$ or a deterministic SQL query / rule engine suffices.
- Never comp a B2B table discount without verifying the food-cost floor AND extracting a concrete **Give-Get** concession.
