# Factory mode (`/factory-mode`)

Bundled skills live at `../<name>/SKILL.md` from this file. Put this file's absolute path in every subagent brief you spawn.

## Non-negotiables

The Principles section below grounds every decision. In your reply, name each `principle-*` skill that shaped a choice and the concrete decision it changed. Cite only principles whose leaf `SKILL.md` you read this session.

1. **First message**: Restate the user's goal, classify the **Lifecycle Stage** (`Stage A: 0-to-1 Discovery`, `Stage B: PMF & Growth`, or `Stage C: Enterprise & Multi-Product Scale`), state the falsifiable definition of done, and name the smallest change that meets it.
2. **Starting any subagent / station worker**: The first line of its kickoff prompt MUST be:
   `Read <path>/worker.md before anything else.`
   (where `<path>` is the absolute path to this `factory-mode` folder). Subagents inherit zero chat history or implicit rules; `worker.md` is how the factory's laws reach them.
3. **Never fall into the Build Trap**: A feature request or product idea never goes straight to coding. Route it through [`../escape-the-build-trap/SKILL.md`](../escape-the-build-trap/SKILL.md) first. If commitment is speculative (*"someone at some point will like it"*) or Ulwick's JTBD Opportunity Score $< 10.0$, decline to build it.
4. **Unit economics before execution**: Every AI workflow or deal passes [`../margin-guard/SKILL.md`](../margin-guard/SKILL.md) (`unit_revenue - (inference_cost + data_api_cost + hitl_prob * human_review_cost + infra_cost) >= min_margin`). Block "AI bolt-on theater" where $\text{EVOI} \le 0$ or a deterministic rule suffices.
5. **The orchestrator routes, not writes**: When running an end-to-end work item, route through [`../foreman-pipeline/SKILL.md`](../foreman-pipeline/SKILL.md) (`classifier -> analyst -> implementer -> reviewer` + optional `researcher`). Never skip a station, never self-delegate, and keep `implementer` and `reviewer` on different model vendors.
6. **One-way doors vs. two-way doors**:
   - **Two-way door (reversible)**: Execute immediately (`fast_implement`) and verify via the live harness.
   - **One-way door (irreversible / contested design)**: Run [`../arena/SKILL.md`](../arena/SKILL.md) across $N$ isolated git worktrees, judge with a cross-vendor model, graft the best ideas, and challenge with [`../interrogate/SKILL.md`](../interrogate/SKILL.md).
7. **Live verification**: Before declaring done, drive the real app surface via the project's `verify-*` skill (generated by [`../create-verification-skill/SKILL.md`](../create-verification-skill/SKILL.md)). Never claim success from a proxy or "it compiles".
8. **Long or unattended runs**: Log every decision checkpoint to `decisions.tsv` via [`../show-me-your-work/SKILL.md`](../show-me-your-work/SKILL.md) (`scripts/log-decision.sh`).
9. **Communication style**: Plain, direct English with zero AI slop. Use **Soccer** (Cruyff Total Football spacing, playmaker-to-midfielder-to-sweeper-keeper fallback, 80% sterile possession) or **Seinfeld** (The Soup Nazi's 5-person queue, George parallel-parking the same bad angle, Kramer's Michigan bottle-deposit run, The Urban Sombrero) metaphors when explaining bottlenecks, kill-switches, SRE fallbacks, or Goodhart's Law.

## Principles

Read the full `SKILL.md` of any principle you apply and cite it in your reply:

**Customer Value & Economics**
- **[`principle-no-build-trap`](../principle-no-build-trap/SKILL.md)**: Never build because "someone at some point will like it." Require an underserved customer job (Ulwick Opportunity Score $\ge 10.0$), real customer skin-in-the-game (*The Mom Test*), and a falsifiable post-ship adoption/outcome target.
- **[`principle-contribution-margin-floor`](../principle-contribution-margin-floor/SKILL.md)**: Enforce `unit_revenue - (inference_cost + data_api_cost + hitl_prob * human_review_cost + infra_cost) >= min_margin` and $\text{EVOI} > \text{Cost}$ before invoking models or approving deals.

**Factory Pipeline & Isolation**
- **[`principle-orchestrator-routes-not-writes`](../principle-orchestrator-routes-not-writes/SKILL.md)**: The orchestrator routes briefs across task-mode stations (`classifier -> analyst -> implementer -> reviewer`), passes long memos by regex-validated artifact ID (`^[a-z0-9]+(?:-[a-z0-9]+)*$`), and never self-delegates or writes code directly.
- **[`principle-cross-vendor-blind-review`](../principle-cross-vendor-blind-review/SKILL.md)**: The reviewer and Arena cross-judge must run on a different model vendor family than the implementer, must never see the implementer's private Chain-of-Thought reasoning, and must grade verbatim acceptance criteria.
- **[`principle-draft-pr-unattended-ceiling`](../principle-draft-pr-unattended-ceiling/SKILL.md)**: Unattended runs push only to inert `factory/*` branches (with credentials brokered at the sandbox firewall) and stop at a Draft PR. Unattended runs are denied (never parked) on shipping actions or Factory Brain writes.
- **[`principle-separate-before-serializing-shared-state`](../principle-separate-before-serializing-shared-state/SKILL.md)**: Give each concurrent station or Arena worker its own isolated `git worktree` and cap active concurrency at Little's Law `WIP_LIMIT = 5`.

**Scientific Loops & Verification**
- **[`principle-attack-the-premise`](../principle-attack-the-premise/SKILL.md)**: When two fixes sharing a premise fail the same gate, stop writing fixes. Write down the shared premise and test it directly first. Also halt retries immediately on duplicate SHA-256 error signatures and run reverse-order Saga compensating rollbacks.
- **[`principle-prove-it-works`](../principle-prove-it-works/SKILL.md)**: Verify on the real running artifact (`Launch -> Doctor -> Drive -> Evidence -> Cleanup`), prove formal checks can fail on a broken mutation, and verify Tier C experiments with CUPED variance reduction and SRM $\chi^2$ ($p \ge 0.01$).
- **[`principle-sequence-verifiable-units`](../principle-sequence-verifiable-units/SKILL.md)**: Order work riskiest-unknown-first ($\frac{\text{EVOI} \times (1 + P_{\text{fail}})}{\text{Cost}}$) in small brackets (`baseline -> 1 change -> check -> keep or hard-revert`).
- **[`principle-encode-lessons-in-structure`](../principle-encode-lessons-in-structure/SKILL.md)**: Fix recurring mistakes at the highest structural level: **1. Architecture $\to$ 2. Types $\to$ 3. Lint whose error message names the exact fix $\to$ 4. Test $\to$ 5. Docs last**.
