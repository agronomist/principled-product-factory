# Principle: One Course at a Time (Sequence Verifiable Units)

Order prep as small, atomic courses that each end in a tasted state, and never fire the next course until the current one passes at the window.

- **Riskiest-Ingredient-First**: When synthesizing a multi-course workflow, place tasting-harness setup first, then order domain steps by $\frac{\text{EVOI} \times (1 + P_{\text{fail}})}{\text{Cost}}$ so cheap, high-information falsification tastings run before expensive slow-braise steps.
- **Keep-or-Dump Brackets**: Each course is `clean baseline -> 1 atomic change -> run live tasting check`. If the check is `VERIFIED` and improves the target reading, commit the bracket and log to `decisions.tsv`. If it regresses or is `INCONCLUSIVE`, dump the pan (hard-revert) immediately.
